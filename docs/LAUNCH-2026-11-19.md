gate means stop and leave the current live release in place.

## Release handoff

After the gates pass, Christian merges the `staging` → `main` release PR and
watches the Workers production deployment. Then, in a private window, he checks
the public home page and `/play`, confirms `/signin` still says accounts are not
open, and confirms the staging preview remains behind Cloudflare Access.

If any check fails, do not merge. Keep the current production deployment and
send the failure details to the lead.
