# Word Path help keyboard coverage

The Word Path route now has a focused 390 × 844 keyboard check for its route-owned help control: native focus reaches the question button, Enter opens the how-to-play dialog, Escape closes it, and focus returns to the question button. Existing pointer-origin sizing, focus-trap, Escape, and focus-return coverage remains unchanged. This is test-only; no product or shared Frame files were changed.
